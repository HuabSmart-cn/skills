# 活动应急预案骨架

- 核验日期：2026-08-22
- 风险等级：高（安全文件，仅作结构骨架，具体内容必须经校方责任主体确认）
- 适用场景：300 人以上活动、户外活动、夜间活动、有校外人员参与的活动，或学校要求提交安全预案/安保方案时

骨架结构综合多所高校公开发布的应急预案共性（山东省高校安全保卫协会预案要素分析、义乌工商职业技术学院、上海体育大学、成都大学、西南医科大学等公开预案），并对应《大型群众性活动安全管理条例》第六条安全工作方案九要素。填写后以本校保卫处、团委要求为准。

## 一、活动基本信息

- 活动名称、主题和内容
- 时间（含进场、撤场）、地点、持续时长
- 预计参加人数、人员构成（校内/校外、有无未成年人或 VIP）
- 主办/承办单位、第一安全责任人（主办单位主要负责人）及联系方式

## 二、组织指挥

- 安全工作领导小组：组长（责任校领导或主办单位负责人）、成员部门
- 现场指挥位置和通信方式
- 工作组分工（按活动规模裁剪，小型活动可一人兼多组）：

| 工作组 | 职责 |
|---|---|
| 指挥部 | 统一协调、信息汇总、向上报告、对外口径 |
| 秩序组 | 入场检票、场内秩序、出入通道疏导、人数上限控制 |
| 消防组 | 消防设施检查、电源火源管控、初起火灾处置 |
| 医疗组 | 现场急救点、过敏与常见伤情处置、与校医/120 衔接 |
| 设备组 | 舞台、灯光、音响、电力、网络的安全运行 |
| 机动组 | 候补补位、突发支援、撤场 |

## 三、风险预判与预防措施

按 `references/campus-safety-and-privacy.md` 的必须核验场景和参加者构成检查逐项排查，至少覆盖：

- 拥挤踩踏：场地容纳量核对、出入通道数量与宽度、缓冲区域、人数实时统计与限流措施
- 消防：灭火器与疏散指示位置确认、易燃物料管控、大功率电器审批
- 天气（户外活动）：恶劣天气判定标准、延期或转移室内的触发条件和通知方式
- 设备与搭建：舞台、桁架、临时设施的搭建方资质和验收
- 食品：供应来源、留样、过敏原提示
- 医疗：急救包、 AED 位置、最近医疗点、救护车进入路线
- 治安：贵重物品保管、纠纷处置、醉酒或滋事人员处理流程

## 四、突发情况处置流程

每类突发情况按"现场第一动作 → 报告路径 → 处置权限"三行写清：

1. 人员受伤：现场急救 → 同时报现场指挥和校医/120 → 秩序组保护现场、疏导围观
2. 火情：初起火灾由消防组扑救并报警（119）→ 同步启动疏散 → 切断相关电源
3. 拥挤踩踏征兆：立即停止入场、打开备用通道 → 秩序组分段疏导 → 必要时中止活动
4. 停电：启用应急照明 → 主持人口播安抚 → 设备组排查，15 分钟未恢复按中止流程
5. 恶劣天气突变（户外）：按预定触发条件转移至室内或延期 → 宣传组同步通知
6. 治安事件：不单独对峙 → 报保卫处/110 → 记录当事人特征

处置原则：先人后物，先控局面再查原因；任何情况下现场工作人员不与冲突对象发生肢体对抗。

## 五、疏散与集合

- 疏散路线图（标注主通道、备用通道、无障碍通道）
- 各区域疏散引导责任人
- 场外集合点和点名方式
- 疏散广播或口令模板

## 六、信息报告

- 事发后第一时间报现场指挥，由指挥部向学校主管部门和保卫处报告，重大情况逐级上报
- 报告要素：时间、地点、事件性质、伤亡情况、已采取措施、所需支援
- 对外信息（含朋友圈、群聊、媒体）统一由指挥部口径发布，工作人员不擅自发布现场信息

## 七、活动后工作

- 撤场检查：电源、火源、遗留物、场地恢复
- 突发情况记录：事实、处置过程、用时、结果，纳入活动复盘
- 向保卫处/团委提交总结（如学校要求）

## 使用规则

1. 本骨架供学生组织者准备材料和与保卫处沟通使用，不是经批准的正式预案。
2. 1000 人以上面向社会公众的活动，安全工作方案须按《大型群众性活动安全管理条例》第六条九要素编制并随许可申请提交，本骨架可作起草底稿。
3. 填写过程中所有"待确认"字段列入活动工作台的待官方核验事项。
