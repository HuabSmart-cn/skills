# 高校活动审批共性模式与核实清单

- 核验日期：2026-08-22
- 风险等级：中（共性模式用于预判和提问，各校具体规定必须向本校主管部门核实）

本文件提炼多所高校公开发布的社团活动管理规定中的**共性模式**，帮助用户预判审批工作量、准备材料、安排倒排时间。它描述的是"普遍长什么样"，不是任何一所学校的具体规定。涉及具体时限、表格、部门、联系人时，一律按 `school-rule-verification.md` 走核验流程。

模式来源（均为学校官网公开文件）：郑州轻工业大学社团活动管理通知、湖南涉外经济学院学生社团管理条例、扬州大学广陵学院社团活动报备年检制度、邵阳学院社团活动审批办事指南、南京工业职业技术大学校园大型活动安全管理规定、山西中医药大学大型活动审批管理规定、枣庄职业（技师）学院大型活动安全管理规定。

## 一、规模分档与审批强度

多数学校按人数分档管理，常见分档模式：

| 规模 | 常见管理方式 |
|---|---|
| 300 人以下 | 社团管理部/团委常规审批，指导教师签字，提前约 1 周 |
| 300—1000 人 | 报保卫处审核，需提交安保工作方案，提前 3—5 个工作日或更久 |
| 1000 人以上 | 触发《大型群众性活动安全管理条例》，提前 20 日向公安机关申请安全许可（见 `regulations-quick-reference.md`） |

注意：分档数字（300/1000）是常见值而非统一标准，部分学校以 200 人、500 人分档。用户学校的具体分档必须核实。

## 二、时间窗共性

| 活动类型 | 常见提前量 |
|---|---|
| 日常小型活动 | 提前 1 周提交申请 |
| 晚会、演出类 | 提前 2—4 周（节目内容往往需单独审核） |
| 大型活动（公安许可范围） | 法定提前 20 日，部分学校内部流程要求提前 30 日启动 |
| 校外集体外出 | 需另附外出活动安全预案，提前量通常更长 |

常见卡点：每周固定审核日（如只在周二、周三受理材料）、纸质材料盖章流转、经费审核与策划终审分两步。倒排计划时把审批等待期作为关键路径，不要把"提交申请"当作"已获批"。

## 三、材料组合共性

一次完整的活动申请通常需要以下材料组合（各校表格名称不同）：

1. 活动申请表（一式多份，手写或系统填报）
2. 活动策划书（目的、内容、时间、地点、参与人员、组织方案、安全预案）
3. 场地申请（教室、体育场馆、室外场地往往分别对应不同表格和管理部门）
4. 经费预算表（涉及经费、奖品、证书时单独审核）
5. 外出活动安全预案（涉及校外时）
6. 赞助协议（有校外赞助时，需合法合规性审核）

## 四、审批链共性

典型流转顺序：

```
指导教师签字 → 业务指导单位/学院团委 → 校团委或社团管理部
                                    ↘ 涉及安全、场地：保卫处/场馆管理部门联审
                                    ↘ 涉及经费：财务部门或社团财务部审核
```

- 指导教师签字是绝大多数流程的第一环，倒排时先确认指导教师可用时间。
- 任何一环驳回都回到起点，材料一次备齐比赶早提交更重要。
- 变更已获批活动的时间、地点、内容，通常需要重新履行审批手续。

## 五、宣传与经费纪律共性

1. 未获审批不得提前进行海报、横幅、喷绘等宣传（多校明文，违规影响社团评优甚至被取消活动）。
2. 报销普遍要求公务卡或对公转账，个人垫付后报销在很多学校不被接受。
3. 活动结束后限期报销（常见为活动结束后一周内一次性报完，逾期不补）。
4. 校外赞助须签订协议并纳入学校财务统一管理，不得私设账外资金。
5. 奖品、证书发放常有比例和流程限制，需要提前报备。

## 六、安全人员配备参考值

个别学校明文规定：安全工作人员配备不低于活动人数的 2%，其中专职安全人员（教职员工、保安、医护）不低于 5‰。此数值可作大型活动人力估算参考，但属于单校规定，引用时必须标注"需以本校保卫处要求为准"。

## 用户核实清单

为用户生成方案时，以下字段标注"待官方核验"并列入待确认事项：

| 核实项 | 建议核实对象 |
|---|---|
| 本校活动审批分档与对应时限 | 校团委/社团管理部 |
| 申请表与策划书模板、固定受理日 | 社团管理部 |
| 目标场地的申请流程和管理部门 | 场馆管理方/教务处/后勤 |
| 安保方案要求与保卫处报备门槛 | 保卫处 |
| 经费申请、报销方式与时限 | 财务部门/指导教师 |
| 校外赞助合规要求 | 业务指导单位/财务部门 |
| 外出活动审批要求 | 校团委/保卫处 |

## 使用规则

1. 用共性模式帮用户预判工作量和时间窗，同时明确告知"这是多校共性，不是你学校的规定"。
2. 共性模式与用户提供或核验到的本校规定冲突时，以本校规定为准。
3. 不得把共性模式中的任何具体数字（分档、时限、比例）写成本校要求。
