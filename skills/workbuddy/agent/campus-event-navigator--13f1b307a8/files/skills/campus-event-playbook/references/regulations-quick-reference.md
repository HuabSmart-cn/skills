# 校园活动法规速查卡

本卡收录与校园活动直接相关的国家级法规关键条款。条款内容以官方发布文本为准，本卡用于快速判断触发条件和时限，引用时注明条文号。

- 核验日期：2026-08-22
- 风险等级：高（直接影响许可义务和法律责任，引用错误后果严重，必须对照官方原文）

## 一、《大型群众性活动安全管理条例》（国务院令第505号）

- 公布：2007-09-14，施行：2007-10-01
- 官方来源：中国政府网；政策解读见应急管理部官网（mem.gov.cn）

### 1. 触发门槛（第二条）

法人或其他组织**面向社会公众**举办的、**每场次预计参加人数达到1000人以上**的下列活动适用本条例：

1. 体育比赛活动
2. 演唱会、音乐会等文艺演出活动
3. 展览、展销等活动
4. 游园、灯会、庙会、花会、焰火晚会等活动
5. 人才招聘会、现场开奖的彩票销售等活动

影剧院、音乐厅、公园、娱乐场所等在其日常业务范围内举办的活动不适用。

判断要点：只面向校内师生的活动通常不属于"面向社会公众"，但多数高校对校内大型活动另有校内审批要求（见 `campus-approval-common-pattern.md`），不得据此直接得出"无需任何审批"的结论。

### 2. 许可机关分级（第十二条）

| 预计参加人数 | 许可机关 |
|---|---|
| 1000—5000 人 | 活动所在地县级人民政府公安机关 |
| 5000 人以上 | 设区的市级人民政府公安机关或直辖市人民政府公安机关 |
| 跨省、自治区、直辖市举办 | 国务院公安部门 |

### 3. 申请时限与材料（第十三条）

承办者应当在活动举办日的 **20 日前**提出安全许可申请，提交：

1. 承办者合法成立的证明以及安全责任人的身份证明
2. 大型群众性活动方案及其说明；2 个以上承办者共同承办的，还须提交联合承办协议
3. 大型群众性活动安全工作方案（见下表九要素）
4. 活动场所管理者同意提供活动场所的证明

安全工作方案九要素（第六条）：

1. 活动的时间、地点、内容及组织方式
2. 安全工作人员的数量、任务分配和识别标志
3. 活动场所消防安全措施
4. 活动场所可容纳的人员数量以及活动预计参加人数
5. 治安缓冲区域的设定及其标识
6. 入场人员的票证查验和安全检查措施
7. 车辆停放、疏导措施
8. 现场秩序维护、人员疏导措施
9. 应急救援预案

### 4. 审查时限（第十四条）

公安机关受理申请后 **7 日内**进行审查，对活动场所进行查验，作出许可或不予许可决定。

### 5. 变更与取消规则（第十五条）

- 经许可的活动不得擅自变更时间、地点、内容或扩大规模。
- 变更活动时间：在原定举办时间之前向许可机关申请变更。
- 变更地点、内容或扩大规模：**重新申请**安全许可。
- 取消活动：在原定举办时间之前书面告知许可机关，并交回许可证件。

### 6. 法律责任（摘要）

| 条文 | 情形 | 后果 |
|---|---|---|
| 第二十条 | 未经许可举办 | 公安机关取缔，对承办者处 10 万—30 万元罚款 |
| 第二十条 | 擅自变更时间、地点、内容或扩大规模 | 处 1 万—5 万元罚款，有违法所得的没收 |
| 第二十二条 | 发生安全事故不立即启动应急预案或不立即报告 | 对安全责任人和直接责任人处 5000—5 万元罚款 |

### 7. 责任原则

承办者对活动安全负责，承办者的主要负责人为安全责任人（"承办者负责、政府监管"，第三、五条）。

## 二、《高校学生社团建设管理办法》（教党〔2020〕13号）

- 印发：2020 年，中共教育部党组、共青团中央联合印发
- 官方来源：教育部及各省教育厅、各高校官网公开全文

### 关键条款

1. 学生社团活动须经申请批准，不得未经批准擅自开展。
2. 社团须有明确的业务指导单位和至少 1 名指导教师；指导教师对社团活动负有指导责任。
3. 经费来源原则上为学校拨款和业务指导单位资助等合法渠道；原则上不接受校外资助、不收取成员会费；确有校外资助需要的，须经合法合规性审核并纳入学校财务统一管理。
4. 学生社团第一负责人不得兼任财务负责人。
5. 学校按平均每生每年不低于 20 元的标准设立学生社团活动专项经费（各高校实施办法普遍援引，具体执行以本校财务规定为准）。
6. 社团实行年审制度，年审不合格整改期间不得开展整改以外的活动。

## 使用规则

1. 用户活动规模接近或超过 1000 人、面向社会公众、或跨省举办时，主动按本卡核对许可义务，并把 20 日申请时限计入倒排计划。
2. 引用条款时写明法规名和条文号；用户需要正式依据时指引其查阅官方原文，不转述为本卡的转述版本。
3. 法规未覆盖的校内管理要求（300—1000 人规模、纯校内活动），转入 `campus-approval-common-pattern.md` 的共性模式处理，并提示以本校规定为准。
4. 本条例自 2007 年施行，引用前注意是否有修订；本卡核验日期为 2026-08-22，距核验日期较久或用户报告条文不一致时，重新核验官方文本。
