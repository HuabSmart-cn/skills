# Graphic Asset Summary Fields

Write `project.resolvedLane`, `project.graphicStrategyGate`, `project.bitmapFirstAllowed`, `project.layoutStaticRequired=false`, `imageAssets[]`, and generated image node registration evidence.

If long or exact editable copy is required, route to `graphic_layout_static` instead.

Also record `project.textCriticality`, `project.copyDensity`, and `project.graphicStrategyRoutingReason`. Bitmap-first completion is invalid when `layoutStaticRequired=true`, `bitmapFirstAllowed=false`, or required exact text remains unresolved.
