# 双屏诊断指南

## 证据层

只读取能改变下一步的状态：

| 层级 | 可用证据 | 能说明什么 | 不能单独证明什么 |
|---|---|---|---|
| 当前布局 | 活动屏数量、坐标、主屏、分辨率、刷新率 | Windows 当前启用的桌面布局 | 线材一定完好 |
| 连接状态 | 活动连接、接口类型 | 系统是否收到显示器连接信号 | 面板一定能正常显示 |
| 显示模式 | 复制、扩展、仅电脑或仅外接 | 当前拓扑选择 | 物理屏与编号对应关系 |
| 编号标识 | 每块活动屏显示短暂编号 | 用户眼前物理屏与系统编号映射 | 未启用屏的编号 |
| 驱动状态 | 显卡或显示设备问题码 | 是否存在驱动层异常 | 一定是最新或最合适的驱动 |

实时状态会在插拔线材、唤醒、开合笔记本盖或切换输入源后变化。只有前提可能变化或即将执行
依赖编号的操作时才重读，不为无关单 action 重跑所有查询。

## 第二屏无信号或识别不到

组合布局和连接状态判断：

- 布局一屏、连接也只有一路：电源、输入源、线材、接口、转接器供电或扩展坞是首要范围；
- 布局一屏、系统存在另一条活动连接：优先检查是否处于仅电脑屏幕模式，并在用户明确修复
  意图下切换扩展后复检；
- 两屏都在布局中但某块黑屏：检查该屏输入源、面板状态、分辨率/刷新率和线材带宽；
- 连接状态读取失败：只能说明证据未知，不能写成“线材损坏”。

不要在没有连接信号时连续切换显示模式。一次物理复测应尽量只改变一个变量，例如更换线材、
换接口或绕过扩展坞，以便定位根因。

## 排列、主屏与编号

- 鼠标跨屏方向错误：当前坐标与实际摆放不一致，只调整目标屏相对位置；
- 任务栏、桌面图标或新窗口默认出现在另一块屏：通常是主屏语义，只切换主屏；
- 用户说“左边那块”“会议室大屏”但系统编号未知：先显示编号，不凭型号或枚举顺序猜；
- 屏幕上下错位导致鼠标只能从局部边缘穿过：根据实际摆放调整上下关系，不一定需要完全交换。

位置和主屏是两个独立属性。任何修复都应避免无关改动。

## 模糊、分辨率和刷新率

外接屏模糊不一定是分辨率：

- 当前分辨率低于 action 返回的最佳候选，且用户明确希望自动修复：可使用正式优化 action；
- 复制模式连接不同原生分辨率的屏幕时，系统可能采用共同模式，先考虑扩展；
- 分辨率正确但文字模糊：检查缩放、应用 DPI 和线材/转接器，不批量改所有屏；
- 目标刷新率缺失：检查接口带宽、线材、显示器菜单和驱动，不默认下载指定厂商驱动；
- action 的“最佳模式”是当前驱动枚举出的候选，不应脱离型号和用户目标宣传为面板绝对原生值。

## 闪烁、花屏和物理故障

持续闪烁、彩条、雪花或接口松动应先做线材/接口/另一设备交叉测试。若画面异常跟随线材或接口，
证据指向链路；若始终跟随显示器，证据指向面板；若截图也包含异常，更偏系统渲染或驱动层。
不要在明显物理损坏的接口上引导反复强插。

## macOS 边界

当前正式能力支持查询/切换显示模式和打开显示器设置，但不保证能自动读取并重排每块显示器的
精确坐标。缺少能力时通过系统设置完成排列，不执行 `ioreg`、`osascript`、Homebrew 安装或
`displayplacer`。外接数量限制应以具体 Mac 型号和 Apple 官方规格为准，不把早期 M1/M2
规则套到所有 Apple 芯片设备。
