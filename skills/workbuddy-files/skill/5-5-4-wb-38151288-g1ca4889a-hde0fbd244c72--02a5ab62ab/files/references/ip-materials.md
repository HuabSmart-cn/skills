# IP 物料延展

把已确认的 IP 角色延展到全系列物料：手办、表情包、换装、场景、海报、周边、材质系列。

> 执行协议见 `miora-creative-core`；锚点链约束见本 skill 主文档（`miora-brand-design`）；
> 角色本身怎么设计见 `brand-mascot.md`。

## 前提：必须先有已确认的角色

本场景**只做延展，不做角色设计**。开工前必须已经有一张用户确认的角色图作为统一参考。

- **用户提供了角色参考图** → 直接当作底稿
- **用户本轮已经做过角色**（走过 `brand-mascot.md`）→ 用那张已确认的主形象
- **两者都没有** → 先做角色形象，再回来。角色设计逻辑见 `brand-mascot.md`

⚠️ 每个物料都必须把这张角色图当参考图带进生成请求。**不要用纯文字重新描述来重画角色**——那样每个物料都会是一个不同的角色，跨物料一致性就没了。参考图带不进去时，本场景交不了：说明情况并停下，不要改成纯文字生成。

## 角色形象确认（如果需要先产出）

用户只有文字描述、必须先锁定形象时，出两张图给用户确认：

### 角色工牌图（竖版）

一张竖版卡片设计：
- **左**：全身 3D 角色（Q 版大头比例，潮玩风格），展示在白色圆角区域内，外圈彩色边框，顶部挂孔装饰
- **右**：角色档案信息区 — 角色名、物种、性格、星座、MBTI、爱好、口头禅等文字字段，每项填上具体内容

整体：干净现代的字体排版，专业角色设定页格式，白底配克制网点纹理；角色部分是 3D 渲染，文字区是平面设计。

### 三视图（横版）

角色的正面、侧面、背面视角，标准站姿，双臂自然下垂，**横向排列**。

⚠️ 硬性要求：
- **三个视角必须是同一个角色**，比例完全一致
- 四条水平虚线对齐辅助线贯穿所有视角，标出头顶、下脸、手、脚的高度
- 半哑光乙烯材质感，柔和高光，光滑漫射上色
- 纯黑背景，极度干净的极简版式
- 顶部居中标题文字

### 循环确认

两张图同时展示；用 `AskUserQuestion` 问是否满意；选项必须覆盖：**两张都可以**、**只重做工牌图**、**只重做三视图**、**两张都重做**。用户指哪张就改哪张；**循环到用户确认为止**。⚠️ 每次重做都是一次计费生成；按 core 主文档第二节重新确认。

确认后，**把这份三视图记为后续所有物料的统一参考图**（按 core `output-contract.md` 绑定语义角色名，如"角色三视图"）。跨物料一致性的通用规则见本 skill 主文档第四节。

## 每项物料必须达到的效果

下面写的是**要达到什么**；具体提示词由你按当前角色信息来写。标了 ⚠️ 的是过往踩坑留下的硬性要求，必须落到提示词里。

### 手办动态展示（盲盒九宫格，方形）

3×3 宫格版式，展示角色作为收藏手办的**8 个不同姿态**，**中心留给品牌识别区**。

姿态来源：坐着、挥手、思考、托腮、抱着爱心、单腿抬起、双臂交叉、比 V。

- 每个手办：光滑哑光塑料质感 + 克制的高光
- 干净浅灰影棚背景，柔和多点照明，每个手办下方有接触阴影
- Q 版比例（头大、身小、圆润形体）
- 3D 渲染，潮玩收藏审美，专业产品摄影构图

### 表情包贴纸集（方形）

**9 张表情贴纸**的 3×3 宫格，深色背景。

⚠️ 每张贴纸坐在**白色圆角矩形卡片**上，略微倾斜（不要摆成完全方正，那样会死板）。

表情来源：开怀大笑、气得冒烟、挥手打招呼、困惑带问号、调皮眨眼、唱歌带音符、握拳坚定、星星眼带爱心、哭着掉泪。

- **2D 平面矢量插画风格**（不是 3D），粗而干净的轮廓，极少阴影
- 来自品牌色板的鲜明颜色
- ⚠️ **每个表情都必须夸张，小尺寸下高度可读** — 这是贴纸的核心要求
- 社媒贴纸包审美，可爱，干净平面设计

### 换装延展系列（换装卡片，竖版）

**6 张角色变体卡片**，白色圆角矩形卡片略微倾斜，**用彩色回形针和细绳图形连起来**，两列版式，纯黑背景。

每张卡片展示角色一套不同主题造型，各带编号（#01–#06）。主题来源：影院引座员制服（马甲 + 领结）、海滩造型（泳裤 + 冲浪板）、休闲西装（配茶杯）、连体睡衣、探险造型（衬衫 + 背包 + 探险帽）、牛仔造型（格子衬衫 + 工装背带裤 + 牛仔帽）。

- 3D 潮玩乙烯手办风格，哑光半亮表面
- 影棚三点光，柔和阴影，Q 版比例
- ⚠️ **每个变体都必须保持角色核心设计的可识别性**；只有服装和配饰主题化

### 微缩场景水晶球（竖版）

**3 个微缩场景**封在**细高胶囊形透明玻璃罩**里（拉长椭圆：圆柱身 + 半球顶），从 3/4 俯视角度观看，纯黑背景。

⚠️ 玻璃罩是这张图的视觉主体；材质必须一眼看得见：
- 真实玻璃属性 — 看得见的反射、弧面上克制的折射、薄边缘高光、罩外表面的镜面光斑
- **玻璃的透明度、反射和材质感必须一眼明显**

⚠️ 三个罩子**纵向叠放，左右错开**，形成波浪状视觉流（不要排成一条直列）。

⚠️ 罩内场景是**简化的微缩模型**，手作树脂 / 塑料玩具感 — 道具应该看起来像小比例量产件（光滑简化形体、看得见分模线、略显敦实的比例），**不是写实环境**。

⚠️ 光线是来自上方的**中性白影棚光**加柔和补光；**不要偏暖或发黄**。

场景来源：角色坐在小扶手椅里（旁边简化壁炉块、微型书架、小灯，底座是白色纹理土丘）；角色坐在小电竞椅面对小显示器（简化键盘和主机块带绘制的 LED 细节，底座是彩色砖平台）；角色在小圆桌旁（简化绿植、注塑迷你灯串，底座是圆形砖纹台座）。

3D 渲染，产品摄影打光，收藏微缩玩具审美，锐利对焦在玻璃罩表面质感。

### 电影感概念场景海报（横版）

角色被放进多个电影感场景的一组海报。

场景来源（每个都有清楚的光线和调色）：
- **竞速** — 角色开卡丁车跑在未来城市赛道上，金色日落光，强动态模糊，广角透视，速度线
- **影院** — 角色站在影院卖品柜台前（爆米花桶、品牌杯），室内环境光，红蓝对比调色
- **太空探索** — 角色穿白色宇航服站在外星沙漠地表，背景是巨大月亮和带环行星、星空，深蓝紫冷调，旁边一个发光伴侣机器人
- **海盗冒险** — 角色在船甲板上看望远镜，帆上有罗盘标记，远处海面有灯塔岛，黄金时刻侧逆光带海面反射

3D 乙烯玩具渲染风格，电影构图，戏剧光，宽银幕比例。

### 周边产品展示（Mockup，方形）

角色品牌周边的干净展示版式，**纯白背景**，专业电商摄影风格。

物件来源：带角色标志性特征的毛绒背包（居中），印着角色脸的 U 型颈枕，一套四张不同造型的角色卡片（彩色边框），一张粗字体排版的活动票，三个不同造型的小毛绒挂件。

- 平铺构图，均匀影棚光，没有刺眼阴影
- 极简现代版式，织物和印刷质感的高分辨率细节

### 材质系列盲盒海报（竖版）

**6 个不同材质**的角色变体，放在**错落的哑光黑阶梯展台**上，纯炭灰黑背景。

⚠️ 版式规则：每个手办站在灰色小方座上，放在**对应盒子的右侧**（盒子在左，手办在右）。

⚠️ 盒子是细高长方体，细腻哑光纸质感，正面有**简化线描角色插画**，且**插画必须直接对应那个变体的材质主题**。盒子颜色呼应各自的手办。

材质变体来源（盒色 / 手办材质成对）：
- 牛皮棕盒配彩色条纹 / 看得见木纹的嵌木材质
- 纯白盒配圆点元素 / 带颗粒填充的半透材质
- 纯黑盒配银色线描 / 带镜面反射的抛光铬钢
- 深紫渐变盒 / 带绒毛质感的彩虹扎染毛绒
- 深绿盒配金色斑点 / 带年代锈迹的做旧铜绿青铜
- 深蓝盒 / 带次表面散射的半透蓝玻璃

专业影棚光（主光从前上方来），克制的轮廓光勾边；盒面印刷相对哑光底有轻微光泽对比。3D PBR 渲染，物理准确的材质模拟，高端收藏玩具摄影，强对比。

### 材质延展图鉴页（竖版）

**6 个材质变体**按 3 行 × 2 列竖向网格排列，纯黑背景。

⚠️ 每个展示单元的构造：
- 深灰**横向胶囊（圆角矩形）背板**
- 角色模型在胶囊**左侧**，**略微溢出框边**做出 3D 跳出感
- 胶囊**右侧**显示材质名（粗白字），下方一个灰色小数字（1/6 到 6/6）
- ⚠️ **不要加额外的描述段落或细节文字** — 这是图鉴页；信息必须克制

材质变体保持**一致的比例和正面站姿**，只改材质：嵌木（彩色几何木块纹理）、透明亚克力（琥珀色填充、可见气泡）、抛光铬钢（环境反射）、柔软毛绒（彩虹绒毛质感）、氧化青铜（铜绿锈做旧表面）、半透蓝灰玻璃（磨砂表面带光线折射）。

一致的柔光箱照明，把每种材质独特的表面属性带出来。干净信息版式，产品图鉴审美，3D 高保真材质研究渲染，暗色高端背景。

## 通用规则

1. ⚠️ **角色一致性是核心** — 生成所有物料时，**必须把已确认的三视图（或用户提供的角色图）作为参考图输入**。**没有任何物料可以只用文字重新描述角色。**
2. **角色名替换** — 提示词里出现角色名的地方，换成用户实际的角色名。
3. **不要水印** — 提示词不含与水印相关的描述。
4. **循环改稿** — 角色确认阶段支持用户反复给反馈并重新生成，直到满意。
5. **批量推进** — 物料生成阶段，选中的多项物料可以并行推进（每批不超过 5 个）；不必逐张等用户确认。

## 交付前检查

除 core `quality-gates.md` 与图片第七节的通用检查外：

- ⚠️ **跨物料 IP 一致性** — 所有物料里是同一个角色：比例、标志性特征、颜色一致。如果角色在某一张里"换了模样"，重做它。
- ⚠️ **全部从角色参考图生成**，不是用文字重新生成的
- **三视图（如果产出了）三个视角是同一个角色**，比例对齐，对齐辅助线贯穿
- **表情包是 2D 平面矢量风格**（不是 3D），每个表情夸张、小尺寸可读
- ⚠️ **水晶球玻璃材质一眼明显**（反射、折射、边缘高光）；罩内是简化玩具感，不是写实环境；光线中性不发黄；三个罩子错开
- ⚠️ **材质系列的盒面插画对应各自的材质主题**，盒子在左、手办在右
- ⚠️ **图鉴页没有额外描述文字**，模型略微从胶囊边缘跳出
- **画幅匹配各物料要求**（方形 / 竖版 / 横版）
- **没有水印，画面里没有规格文本**
