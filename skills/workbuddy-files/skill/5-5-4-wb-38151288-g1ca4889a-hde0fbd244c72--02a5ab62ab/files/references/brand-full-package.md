# 品牌全案 / VI 系统

整套品牌视觉识别物料。**进入本文之前，`miora-brand-design` 主文档里的意图识别和方向确认必须已经做完。**

> 执行协议见 `miora-creative-core`；
> 品牌信息采集、按行业推断风格、锚点链约束见本 skill 主文档（`miora-brand-design`）。
> 本场景的 5 项物料共享一套设计系统；这是典型的"一套" — 锚点链纪律必须严格执行。

## 交付物

| # | 物料 | 画幅 | 内容 |
|---|---|---|---|
| 1 | Logo + Slogan | 方形 | 品牌标志 + 标准字组合 |
| 2 | VI 手册总览 | 竖版 | 颜色、字体、Logo 规格、物料预览 |
| 3 | 社媒模板组 | 竖版 | Story 模板（放进手机里）+ 视频封面模板 |

| 5 | IP 形象三视图 | 横版 | 品牌吉祥物工业设计视图 |

**延展物料**（核心 5 项做完后，用 `AskUserQuestion` 让用户多选要不要继续）：

| 物料 | 画幅 | 内容 |
|---|---|---|
| 门店场景 | 横版 | 写实门店 / 空间建筑可视化 |
| 宣传海报 | 竖版 | 品牌战役海报，主视觉 + 文案 |
| 生活方式营销图 | 竖版 | 编辑风格的生活场景产品摄影 |

延展只在核心 5 项全部交付之后再问；不要一上来就把 8 项都列给用户 — 那样会让人不知道从哪下手。

## 硬顺序

1. **先做 Logo，并确认它**（用户已经有 Logo 就直接用，跳过创建）
2. **以确认后的 Logo 为参考图**产出物料 2–5
3. 核心 5 项做完 → 问延展
4. 延展物料同样以 Logo 为参考图

Logo 确认之前不要做任何其他物料。每项物料的提示词都必须写明：完整复现参考图里的 Logo 标志、颜色和字体风格；不要重画、不要改色、不要改比例。

Logo 怎么做（多概念探索、迭代收敛）：见 `brand-logo.md`；IP 形象的角色设计逻辑：见 `brand-mascot.md`。不要在这里另写一份更浅的版本。

## 每项物料必须达到的效果

下面写的是**要达到什么**；具体提示词由你按当前品牌信息来写。标了 ⚠️ 的是过往踩坑留下的硬性要求，必须落到提示词里。

### 1. Logo + Slogan（方形）

品牌标志与标准字的纵向叠放组合，居中，浅色干净背景。

- 图标：品牌的核心符号，粗圆角线条，用主色渲染
- 图标下方：品牌名（粗黑体无衬线，字母略圆，现代几何感）
- 底部：英文名或 slogan（全大写，干净粗无衬线）
- 整体：现代年轻，平面插画感，粗线条，可缩放的矢量感

### 2. VI 手册总览（竖版）

一页专业品牌 VI 手册版式，白底，**从上到下三块横向分区**：

- **上 — 品牌基础**：Logo 横版和竖版组合；色卡（每种颜色一块大色块，色值标在下方）；字体样张（主展示字体的多种字重）
- **中 — 产品样机**：已应用 Logo 的产品和包装；印着品牌名和 slogan 的包装；品牌贴纸徽章；标志性图形母题
- **下 — 应用物料**：会员卡、小票（带品牌页脚）、名片（正面 Logo，背面图标）、服务牌

整体：粗字体、平涂色块、粗轮廓、模块化网格、高信息密度、专业品牌规范格式。

⚠️ 色卡下方的色值标注是**这份物料唯一允许出现色值文字的地方** — 因为色值本身就是 VI 手册的内容。其余所有物料都不许把色值画进画面。

### 3. 社媒模板组（竖版）

白色展示背景，左右分区：

**左 — Story 模板**：放进手机里的竖版内容模板

⚠️ 手机样机防变形规则（不遵守会画出比例变形的手机）：
- **只放 2 部手机，不要放 3 部**。错落重叠摆放（一部略靠后，倾斜约 5°），让每部手机都有足够宽度渲出正确比例
- 每部都必须有**清晰可见的粗圆角边框**（深灰或黑色机身边框）；圆角必须对得上现代手机（画面里的视觉圆角必须够大）
- 顶部必须有刘海或 Dynamic Island 区域；底部必须有 home 指示条
- **屏幕内容严格 9:19.5 比例；不许拉伸去填空间**
- 两部手机（含边框）合计约占画幅宽度的 40–45%

前机屏幕内容：新品揭示（大字标题 + 产品剪影 + 品牌识别 + 底部行动按钮）
后机屏幕内容：互动 Story（主色背景 + 互动提问文案 + 投票/进度指示）

**右 — 视频封面和卡片模板**：2–3 张平面图形卡片，不要手机框
- 主色背景 + 一句有冲击力的钩子问题 + 居中品牌图标 + 辅色装饰边框
- 中性浅色卡片 + 条码元素 + 进度条 + 状态文字
- （可选）小方形卡片 + 品牌吉祥物贴纸 + 标语

整体：紧凑粗无衬线、平涂色块（主色和辅色）、年轻现代审美。

### 4. 包装物料样机（竖版）

品牌包装与整套物料的平铺样机，**俯视等距视角**产品摄影。

- 物件：印着大字 slogan 的纸袋、带品牌名标签的容器、带钩子文案的套筒、印 Logo 的封口贴、带品牌页脚的小票、方形贴纸、名片、小配件
- 摆放：乱中有序（有组织的随意感）；不要摆成整齐网格
- 材质：高质量哑光纸质感，看得见折痕和真实厚度，柔和自然阴影
- 颜色：主色 + 辅色 + 白/米色，暖白底上高对比

⚠️ 每个带品牌的物件都必须露出参考图里的那个 Logo；不要露出变形或重画的版本。

### 5. IP 形象三视图（横版）

品牌吉祥物的工业设计视图页。

- **四个视角横排**：正面、3/4 侧面、侧面、背面
- 角色概念：拟人化的品牌相关物件，圆润身体
- 特征点：头部造型、用品牌核心符号作主要面部特征、配饰、胸章、短粗四肢和圆手、手持道具、背面细节
- 边缘可以加圆形引出标注（英文标签，如 "LOGO SYMBOL DETAIL"）
- 顶部标题：品牌英文名
- 纯白背景配一条水平基线，高质量 3D 渲染感

⚠️ 角色设计必须继承 Logo 的核心符号、颜色和图形语言 — 它是品牌的延展，不是一个独立角色。

⚠️ 四个视角必须是**同一个角色**，身高和比例一致。

### 延展 — 门店场景（横版）

写实门店街景，行人眼高、从人行道对面拍，覆盖完整店面宽度，透过玻璃看见室内纵深。

- 建筑与布局：开放或玻璃门面；一侧 L 形服务台（上方是品牌数字菜单板）；另一侧顾客区（嵌入式长凳、小桌、吊灯）；干净地面
- 品牌落位：立面大型发光品牌名和 Logo；品牌色作为吧台、家具面料、霓虹招牌的点缀；室内特色墙上超大品牌图形母题；外带杯、员工围裙、门口立牌上都有 Logo
- 光线：分层暖光（背光招牌、檐下灯带、轨道灯、桌面吊灯），整体明亮舒适，从外面看有吸引力
- 材质按品牌调性选（深色木饰面 / 金属 / 混凝土等）
- 氛围：黄昏，室内暖光对比暮色天空

风格：建筑可视化，写实渲染，35mm 视角，轻微景深。

### 延展 — 宣传海报（竖版）

- 上三分之一：Logo 醒目放置 + 品牌名
- 中部：主视觉（按行业适配 — 餐饮用产品特写，时尚用模特，护肤用功效演示）
- 下三分之一：大字 slogan + 小字日期/地点行 + 二维码或社交账号占位
- 颜色：主色和辅色主导，深中性色给文字
- 品牌图形母题作为装饰元素框住主视觉
- 高对比，能从远处抓眼

⚠️ 视觉层级必须清楚：Logo → 主视觉 → 文案 → 行动号召。

### 延展 — 生活方式营销图（竖版）

编辑风格的生活摄影，品牌产品自然嵌进真实生活瞬间。

- 场景按行业适配：咖啡/茶 → 年轻人在阳光窗边享用；护肤 → 早晨浴室仪式；潮牌 → 都市街头风瞬间；食品 → 朋友在漂亮餐桌上分享
- **产品在场但不是刻意居中** — 它是这个瞬间的一部分，不是产品特写
- 产品包装上的 Logo 以自然角度可见；品牌色在环境里克制地呼应（服装、家具点缀、墙面装饰）
- 摄影风格：自然柔光（黄金时刻 / 窗光 / 阴天漫射），浅景深，主体清晰背景柔化，略暖调色
- 抓拍感、真实感；**不要看起来摆拍，不要看镜头，不要有图库照感**

## 交付前检查

除 core `quality-gates.md` 与图片第七节的通用检查外：

- **完整 5 项（+ 选中的延展）在颜色、字体、图形语言上一致** — 看起来是一次设计出来的
- **Logo 在所有物料上缩放和落位正确**，并与定稿完全一致（没有重画或改色）
- **IP 形象与品牌视觉相连** — 在颜色 / 符号 / 概念上读成同一个品牌
- ⚠️ **手机样机比例正确** — 只有 2 部手机，边框清晰可见，屏幕 9:19.5，没有纵向拉伸或压扁，错落摆放而不是挤成一排并排
- **图上文字语言统一**（标签、标语、UI 文字、标注）
- **除 VI 手册色卡外，画面里没有色值文字**
- **没有编造的奖项、认证、专利或合作方标志**
