# Logo 设计

品牌标志与高端展示图。

> 执行协议见 `miora-creative-core`；
> 品牌信息采集、推断规则、锚点链约束见本 skill 主文档（`miora-brand-design`）。

## 范围边界

**适用**：Logo 概念探索 → 迭代收敛 → 定稿 → 多种背景风格的展示图。

**不适用**（这些是其他场景）：
- **有脸有身体的角色形象** → `brand-mascot.md`。Logo 是抽象符号；吉祥物是角色。
- **App 图标** → `app-icon.md`。App 图标有一套系统约束：1024 方形，不许自己画圆角，不许把光影烤进图标，等。
- **一整套品牌物料** → `brand-full-package.md`。
- **矢量文件（SVG）、网页、打包文件**。交付的是位图 + 展示图。

## 必填输入

- **品牌 / 产品名**（本地语言 + 英文，如果是双语）— 缺这个就卡住，因为标志和标准字都依赖它。直接问。
- **Logo 类型** — 仅图标 / 仅标准字 / 图标 + 标准字组合。这决定怎么往下走。用户说不清时，默认**图标 + 标准字组合**，并说明这个假设。

选填（没给就推断并告诉用户）：行业 / 品类、核心概念（连接、流动、安全、简约……）、设计偏好（极简 ↔ 复杂、几何 ↔ 有机、单色 ↔ 指定色板、冷 ↔ 暖、专业 ↔ 亲和）。

## 流程

### 步骤 1 — 概念探索

**至少出 6 个概念**，每个必须**真正不同**（不同的构成思路 / 构图逻辑），不是同一个想法微调参数。

从这些方向取材，保证多样性：
- 几何原语标志
- 点阵 / 网格图案
- 线系统 / 节点网络
- 负空间标志（用留白构成形）
- 字母组合 / 首字母标志
- 几何与线的混合构成

每个概念配**一句设计理由**，把视觉接到品牌概念上（不要写空话；说清这个形状为什么代表这个品牌）。

概念图的提示词要点：
- 单个居中标志，平面纯色背景，高对比，干净边缘，可缩放的矢量感，专业品牌识别
- 不要用摄影质感，不要用 3D 倒角效果（除非用户要求）
- 标准字要把品牌字母**逐字拼写准确**，并写明字重和大小写（如"粗几何无衬线、全大写"）

⚠️ 这条路径**出不了透明底**；干净的平面纯色背景就够。不要在提示词里承诺透明。

### 步骤 2 — 迭代收敛

- 帮用户从 6+ 个收窄到 2–3 个偏好方向
- 做**针对性**改稿（调颜色、间距、字重，加渐变，精修符号，合并两个概念的元素）
- **每次改稿都必须把上一版的实际图带进请求当参考图**；不要用文件名或口头描述指代
- **不要整张重做**，除非用户明确要求
- 用户锁定最终方向后，**存为定稿** — 之后所有展示图都必须以这张图为参考。定稿是本场景的锚点；锚点链的通用规则见本 skill 主文档第四节

### 步骤 3 — 展示图

1. 从下面的**背景风格库**里挑 **4** 个匹配产品类型和调性的，并说明每个为什么合适
2. 每张展示图都以定稿为参考图生成：
   - 提示词要求：完整使用提供的 Logo 图；保持形状、比例、颜色不变；把它作为所述背景场景里的主体；**不要重画、不要改这个标志**
   - 按用途选画幅（方形或横版）

### 步骤 4 — 交付

- 6+ 个初始概念（附设计理由）
- 定稿
- 4 张不同背景风格的展示图

## 背景风格库

**暗色系列**
- **绝对虚空** — 极端极简、硬核科技；近黑无缝空间，一盏柔和主光
- **磨砂穹顶** — 现代留白、高端产品；磨砂玻璃穹顶，柔光漫射，光衰减
- **流体深渊** — AI 原生流动感；暗色流动液体 / 变形体，动态纵深
- **实体影棚** — 影棚灯光、编辑级完成度；暗色无缝背景 + 受控硬聚光
- **实体流体** — 创意品牌；实色地面上的金属微光泽，克制的液体反射
- **数字硬件** — 赛博 / 数字复古；暗色场景 + LED 点阵光点缀

**亮色系列**
- **纸质编辑** — 人文品牌；特种纸质感，印刷编辑排版感
- **虹彩磨砂砂面** — 科技硬件；虹彩光学材质，磨砂半透，克制的彩虹光泽
- **晨雾光场** — 亲和的 AI 产品；柔和晨雾光场，轻渐变
- **无菌影棚** — 算法驱动品牌；干净明亮的无缝影棚，空间秩序，利落阴影
- **容器化 UI** — SaaS 平台；Logo 呈现在干净的数字 UI 容器 / 卡片里
- **瑞士平面** — 持久权威；绝对平面的纯色场，瑞士风负空间

## 设计原则

1. **多样性** — 至少 6 个真正不同的概念，让用户有真实选择
2. **从简单起** — 先做一个干净的原语；概念需要时再加复杂度
3. **有含义** — 每个视觉元素都必须接到产品的核心概念；不要做纯装饰
4. **可缩放** — 标志从 favicon 到广告牌都要站得住
5. **专业水准** — 对齐高端品牌识别的标准
6. **一致性** — 每张展示图都复用定稿；标志绝不重画或改动

## 交付前检查

除 core `quality-gates.md` 与图片第七节的通用检查外：

- **6+ 个初始概念**，视觉上每个真正不同，每个都有设计理由
- **展示图是以定稿为参考图生成的**，不是用文字重新生成的 — 标志保持完全一致
- **有且只有一份定稿**作为所有展示图的来源
- **标准字字母准确** — 拼写、大小写、字重与品牌规格一致
- **标志在极小尺寸下仍能认出来**（缩到 favicon 大小仍可辨认）
- 没有输出 SVG、网页或打包文件
