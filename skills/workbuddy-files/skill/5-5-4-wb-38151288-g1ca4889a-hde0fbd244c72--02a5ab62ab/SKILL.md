# Miora 品牌设计

🔴 **先检查 `miora-creative-core` 加载了没有。没有就立刻 `Skill(miora-creative-core)`，再往下读。**

品牌视觉资产的**决策层**。

## 适用与不适用

**适用**：Logo、品牌吉祥物 / IP 角色、品牌 VI 全案、IP 物料延展。

**不适用**（这些在 `miora-image-generation`）：
- 电商详情图 / 商品详情页模块图
- App 图标（有一套系统约束：1024 方形，不许自己画圆角，不许把光影烤进图标，等）
- 普通海报、插画、单张图

## Reference（按需加载）

先做意图识别，再只加载匹配的那一份：

| reference | 什么时候加载 | 交付物 |

| `references/brand-logo.md` | 只做 Logo / 品牌标志 | 多方向概念稿 + 定稿 + 展示图 |

## 一、先做意图识别：认清需求范围（必须做，不许猜）

不同品牌需求范围的产出规模**相差 5 倍以上**。猜错的代价是用户白花钱，再加上一串针对无效生成请求的连续确认。

| 用户表达 | 判断 |
|---|---|
| 全案、VI、视觉识别系统、整套品牌物料、品牌手册、企业形象设计 | 全案 |
| Logo、标志、商标、品牌标记，且**没有提到其他物料** | 只做 Logo |
| 吉祥物、IP 形象、品牌角色、品牌人物、代言角色 | 只做吉祥物 |
| 用已有的 IP 角色做周边、盲盒、表情包、材质变体 | IP 物料延展 |
| 只说"品牌设计"、"帮我做品牌"、"品牌视觉" | **说不清 → 必须问** |

### 说不清时怎么问

用 `AskUserQuestion` 问；每个选项都必须带上**产出规模**，好让用户判断：

- **完整 VI 全案** — 一整套 Logo、VI 手册、社媒模板、包装样机、IP 形象等；5+ 张，分多批推进
- **只做 Logo** — 先出多方向概念稿；选定后再做展示图
- **只做吉祥物 / IP 角色** — 角色形象加三视图、表情、姿态

这次范围提问可以和 core 主文档第二节的开工确认合并成一次；不要问两遍。

⚠️ **不要默认走全案。** 全案是最贵的选项；用户没明确说就要默认全案，等于替用户花钱。

### 递进关系

这些不是互斥的，是递进的：

- 全案内部**已经包含** Logo 和 IP 形象阶段 — 进入全案后，Logo 阶段按 `brand-logo.md` 做，IP 形象阶段按 `brand-mascot.md` 的角色设计逻辑做；**不要在全案里另写一份更浅的版本**。
- 用户先做了 Logo，再说"再帮我扩展成整套" — 已确认的 Logo 直接当作全案锚点；**不要重做 Logo**。
- 用户先做了吉祥物，再要周边物料 — 已确认的角色三视图直接当作 `ip-materials.md` 的统一参考图；**不要重新设计角色**。
- 用户先做了全案，再说"Logo 我想多看几个方案" — 进入 `brand-logo.md` 的概念探索，但带上已经确认的品牌信息；**不要什么都从头再问一遍**。

## 二、品牌信息采集（各分支共用）

**必填**（缺了就问，因为整套设计都从这里长出来）：
- **品牌名** — 本地语言 + 英文（如果是双语品牌）
- **行业 / 品类** — 决定风格推断、物料类型、视觉语言

**选填**（没给就推断，并在回复里告诉用户你的推断）：
- 品牌标语 / slogan
- 风格方向
- 配色偏好
- Logo 概念描述（如"一个杯子中间有只眼睛"）
- 目标受众
- **已有 Logo 图** — 用户已经有 Logo 时，**跳过 Logo 创建阶段**，直接把它当作后续所有物料的锚点参考图

### 推断规则

用户没给时，按这个顺序推断；不要留空，也不要反复追问：

- **没给风格** → 按行业 + 品牌名的气质匹配（见下表）
- **没给颜色** → 从风格方向推导主色 + 辅色 + 中性色
- **没给 Logo 概念** → 从品牌名的含义生成标志概念
- **没给 slogan** → 从品牌定位生成

### 按行业推断风格

| 行业 | 默认风格 | 默认配色 | 默认视觉母题 |
|---|---|---|---|
| 奶茶 / 咖啡 | 新瑞士风、大胆 | 高对比撞色 | 数码科技感（进度条、电量） |
| 护肤 / 美妆 | 极简轻奢 | 柔粉 + 金 | 有机曲线 |
| 潮牌 / 服饰 | 街头先锋 | 黑 + 霓虹 | 涂鸦 / 像素 |
| 食品 / 烘焙 | 温暖手作 | 暖棕 + 米白 | 手绘插画 |
| 科技 / 互联网 | 未来极简 | 冷蓝 + 白 | 几何线条 |
| 母婴 / 儿童 | 柔软活泼 | 马卡龙多彩 | 圆润卡通 |

这张对照表是起点，不是终点。品牌名本身的气质，以及用户给的任何线索，都优先于表。

## 三、方向确认（进入生成之前）

推断完成后，**先把方案摆给用户确认**，再开始生成。这一步是为了避免整套图都走错方向。

必须说清：风格方向、色彩体系（主色 / 辅色 / 中性色）、Logo 概念、slogan、IP 形象基础概念（范围包含时）。

然后说明接下来的顺序：**先做 Logo；Logo 确认后再做其余物料** —— 因为其余物料都必须以确认后的 Logo 为参考图。

给用户三个选择：确认并开工 / 调整某一项 / 推倒重来。

## 四、锚点链（品牌一致性的根基）

品牌物料只有**处处一致**才站得住。没有模板引擎；一致性完全靠**一个已确认的锚点 + 以参考图派生**。

### 4.1 锚点是什么

| 分支 | 锚点 |
|---|---|
| Logo 设计 | 定稿（所有展示图都从它派生） |
| 品牌吉祥物 | 已确认的主形象（正面、中性亲和、全身） |
| 品牌全案 | 已确认的 Logo（用户已经有 Logo 就直接用） |
| IP 物料延展 | 已确认的角色三视图（或用户提供的角色图） |

### 4.2 五条硬规则

1. **先确认锚点，再做其他物料。** 顺序不许反。锚点是整套的基准；基准没定就批量生产等于批量返工。
2. **用户已经有对应资产时，那就是锚点**；不要再新做一个。
3. **后续每张物料都必须把锚点带进请求当参考图**，⚠️ **不许只在提示词里用文字描述**。"上次那张"、"之前的风格"不算。
4. **每条派生提示词都必须写明保什么、改什么。** 只说"要一致"没有约束力；写具体：完整复现参考图里的标志 / 角色；保持形状、比例、颜色、字体风格 / 标志性特征不变；不要重画、不要改色、不要改比例；只改用户要求的那一项。
5. **锚点还没确认时，停下来先把它做完**；不要先做其他物料。

### 4.3 必须逐项列出的不变量

按分支选：

- **Logo / 标志** — 形状、比例、颜色、结构、字重、留白
- **角色 / 吉祥物** — 比例、标志性特征（逐项列出：耳朵形状、花纹、配饰等）、颜色、风格、表情基线
- **全案物料** — Logo 标志、色彩体系、字体系统、图形母题

### 4.4 产物与跨轮次延续

- 按 core `output-contract.md`，锚点必须绑定一个**语义角色名**（如"品牌Logo"、"角色主形象"）；后续所有物料都通过这个名字引用它；**一次生成请求只做一个物料**；一次请求返回多张，只算同一物料的候选版本。
- 用户认可锚点后，**把锚点产物连同当时的风格描述一起留存**（两样都要）—— 下一轮用户说"再加几个物料"时要靠它接住。
- 后续轮次先确认锚点引用仍然有效；无效就说明情况，请用户再提供一次；⚠️ **不要凭记忆重述原来的品牌视觉**，那样一定会走样。

## 五、品牌设计通用底线

- **统一图上文字的语言。** 默认跟品牌的目标市场；用户指定了就跟随。整套物料的语言必须一致。
- **不要抄袭。** 用户提到的竞品或参考品牌只作方法参考（比例逻辑、简约度、调性）；⚠️ **绝不复制受保护的标志、角色设计或商业外观**。
- **不要编造资质。** ⚠️ 不要在物料上虚构奖项、认证、专利或合作方标志。用户没提供的荣誉标识不许画上去。
- **Logo 必须能缩放。** 标志在极小尺寸（favicon、app 角标）和极大尺寸（店招、广告牌）都要站得住。检验标准是缩得很小时是否还能认出来。
- **一套物料，一套设计系统。** 颜色、字体、图形母题、留白节奏在各物料间保持一致，让整套看起来是一次设计出来的。

## 六、Prompt 与画幅

品牌物料的 Prompt 构建、比例推断、图上文字规则，和普通图片一样：

- **已经是完整详细的描述 → 逐字透传**；含糊 → 沿用户未指定的维度补充（主体、环境、视觉风格、光线与构图、色彩氛围、渲染细节）。
- **带参考图时描述"改什么"**，不要把整张画面重新描述一遍。
- 要渲染指定文字时（品牌名、slogan），保持其**内容、语言、标点、大小写完全不变**。
- ⚠️ **绝不把规格画进画面** — 色值代码、字体名、字段标签词、结构说明、提示词片段，不许出现在图上。唯一例外是 VI 手册上的色卡标注（色值本身就是手册的内容）。
- 按物料用途选画幅；每个 reference 有具体要求。

## 七、交付前检查

按 core `quality-gates.md` 做通用验证。品牌特有的：

- **锚点确实被当作参考图用了** — 派生物料是按参考图生成的，不是用文字重新生成的
- **有且只有一个锚点** — 中途不要换基准
- **不变量逐项对得上** — 每张派生物料都对照锚点逐项核对
- **整套设计系统一致** — 各物料的颜色、字体、图形语言统一；看起来是一次设计出来的
- **没有编造的品牌名、标志、奖项或认证**
- **图上文字语言统一**
- **Logo 在小尺寸下仍能认出来**
- **整套物料在同一张画布上** — 锚点与所有派生物料在同一张 `.miora` 上

每个 reference 有自己更严的验证清单；**以 reference 的清单为准**。
