# 竖屏短视频 / 带货视频

社媒竖屏短视频的内容设计。

---

## 一、先定视频类型（决定整个结构）

类型决定黄金结构与分镜构成，**是第一个要明确的东西**。用户的需求里没有明确类型时**必须问**（把下表的类型作为选项），不要猜——类型选错整条视频的结构都不对。这次提问可以和开工确认合并成一次。

| 类型 | 结构特征 | 是否需要出镜人 |
|---|---|---|
| **开箱** | 包装揭示 → 第一眼 → 关键特征 → 使用中。好奇感强、节奏快 | 不需要（手 + 产品即可） |
| **测评** | 口播走一遍优点、诚实的缺点、结论 | 需要 |
| **故事短剧** | 一个小情境里产品解决痛点（问题 → 挣扎 → 产品 → 缓解） | 需要 |
| **教程** | 一步步演示"怎么用 / 怎么做到这个效果" | 不需要 |
| **对比** | before/after 或 我们 vs 别家 的并列证据 | 不需要 |

类型与更低层的选择冲突时，**以类型的结构约定为准**。

## 二、黄金结构（决定分镜表）

每条视频都按这条时间线规划（默认总长 15–45 秒，按用户目标长度收紧）：

- **0–3 秒 钩子（必须有，最重要）** — 让人停下来划。一个有冲击力的画面 + 一句钩子文案。钩子模板：
  - **痛点式**："还在为[烦人的问题]困扰？看这个。"
  - **悬念式**："我原本不信，直到……" / "看到最后"
  - **对比式**：第一帧就给极端的 before vs after
  - **数字式**："3 个原因让它卖断货" / "9 块 vs 90 块，看出区别了吗"
- **3–10 秒 铺垫 / 兴趣** — 引入产品与承诺，保持势头
- **10–20 秒 演示** — 展示它在工作 —— 核心卖点时刻（使用中、开箱揭示、教程步骤、转变过程）
- **20–30 秒 证据 / 价值** — 结果、利益兑现、可信度（质感特写、before/after、"你看这个"）
- **收尾 行动号召** — 明确告诉观众做什么。**绝不无 CTA 收尾**

每个节拍映射到一个或多个镜头。每个镜头都要有：目的、画面动作、镜头处理、字幕文案、时长。

**只能做单镜头时** —— 把黄金结构**压缩到一个镜头里**（通常取钩子 + 演示，用一个连续动作完成），或者把完整结构作为规划文档交付。

## 三、画幅与安全区

- **竖屏 9:16**
- 主体**居中或偏上三分之一**
- **顶部留出钩子字幕空间**，**底部的互动区**（点赞、评论、购物车按钮所在）**不要放关键内容** —— 那部分会被平台界面盖住

## 四、镜头设计

每个镜头的提示词里都要包含：

- **构图** — 三分法、产品主体居中、对角构图给动感、框中框聚焦
- **光线** — 三点光：主光在前侧约 45°、补光柔化阴影、轮廓光把主体从背景分离。美妆 / 食品用柔和均匀光；数码 / 硬核风用强对比
- **机位按意图** — 平视 = 自然亲和；俯视 = 干净的产品展示；仰视 = 权威 / 高端；45° = 拍人显得好看
- **镜头运动** — 推进（强调）、拉远（揭示环境）、横摇（扫一排）、跟随（追动作）、环绕（产品主体旋转展示）。**克制叠加**
- **品类线索** — 食品 → 蒸汽、质感微距、暖光；美妆 → 干净肤质、色卡特写、柔光；服饰 → 动态、垂坠、先全身后细节；数码 → 锐利边缘、屏幕点亮镜头、暗色高端场景

## 五、出镜人处理

需要人出镜时，**在文生视频的提示词里直接描述出镜人**：写一段详细、固定的人物描述（脸型、年龄、发型、服装、表情），**每条镜头提示词里都原样复用**。

**不要先生成一张人物图再用它去做视频** —— 那张中间人物图是常见的失败点（平台会拦）。

产品镜头（不出镜）时，同样把产品描述在每条提示词里保持一致。

严格的跨条人物一致性**依赖角色一致性资产**，靠文字描述复用只能逼近。用户对此有硬要求时如实说明，不要硬做然后交付一堆人物对不上的视频。

## 六、脚本写法

- **口语化**，不是书面语。对着一个观众说话（用"你"）
- **短句**（每句约 10 词以内），字幕才放得下、节奏才快
- **价值前置** —— 第一句就是钩子
- **一条视频一个核心信息**，以 CTA 收尾
- 交付形式：钩子句 → 逐节拍口播 → CTA 句，配一份带时间码的字幕列表

## 七、字幕与音频计划（作为规划交付，不是成片）

- **字幕必须有**：清晰的粗无衬线字、按手机屏调大小、放在下三分之一、**白字加黑描边**（通用的高对比方案）。每句口播都要配字幕，**钩子那句最大**。每行短（约 10 词以内）
- **音频层**：视频本身携带的是口播与环境音。**背景音乐不要放进生成的片段里**，它是后期的独立层
- **背景音乐**：作为计划给出 —— 匹配情绪（欢快 / 温暖 / 紧张 / 励志）与剪辑节奏（快切配快节奏音乐）。推荐**风格方向**而不是具体的版权曲目。不生成音乐
- **节奏**：快切 1–3 秒适合有活力的 / 开箱 / 钩子；慢一些 3–8 秒适合故事 / 情绪 / 教程。每约 5 秒给一个信息点，注意力才不掉
- **转场**：硬切（默认、有节奏感）、淡入淡出（柔和）、推拉（强调）。**带货视频优先硬切**

---

## 八、交付前检查

除 core `quality-gates.md` 与 video 的交付前检查外：

- **钩子测试** — 0–3 秒能否独立地让人停下来划（有冲击力的画面 + 钩子文案）？不能就重做开头
- **产品完整性** — 产品的形状 / 颜色 / 标识 / 比例与用户提供的照片一致（如果有产品照）
- **出镜人连贯** — 同一条视频里人物的脸 / 服装 / 发型 / 光线一致
- **竖屏安全区** — 主体居中 / 偏上；顶部字幕区与底部互动区没有关键内容；画幅是 9:16
- **结构完整**（做完整视频或规划时）— 钩子 → 铺垫 → 演示 → 证据 → CTA 都在；每约 5 秒一个信息点；**以 CTA 收尾**
- **字幕计划完整** — 每句口播都有字幕、下三分之一、白字黑边、短行、钩子最大
- **如实说明交付形态** — 单镜头视频就说单镜头；只有规划文档时明确说这是分镜 / 脚本 / 字幕计划，**不是成片**，不要让用户以为拿到了可发布的视频
