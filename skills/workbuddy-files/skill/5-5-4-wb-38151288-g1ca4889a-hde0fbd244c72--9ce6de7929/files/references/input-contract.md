# 输入契约

用户附件与参考素材的处理规则。**用户带了附件或参考素材时才需要读本文**；参数怎么定在主文档第二节。

## 一、用户附件

- 附件的可用路径由**宿主提供**。拿上下文里已经给你的引用；**不要猜测或推断文件位置**。
- 场景要求必须有参考图时（如电商详情图必须有产品实拍），而上下文里没有可用的图片引用，**停下问用户要**；不要用纯文生图代替。
- 用户只给了图片内容、没有可用路径时，同样不要自己重建或猜测文件位置——说明情况，等可用引用到位。

## 二、参考素材

### 2.1 全部带上，不要静默丢弃

收到的参考素材必须**全部带进**生成请求；不要静默丢弃、抽样或去重。

某份素材无法用于当前生成方式时（如给只接受图片的生成喂了一段视频），**说明排除了它以及原因**；不要吞掉不提。

### 2.2 超过上限时怎么处理

参考素材有数量上限时（上限由工具决定），超了**不要静默截断**：

- 告知上限
- 按用户可见顺序保留前 N 个，**或**问留哪些

⚠️ 静默截断会让用户以为所有素材都生效了，实际结果却只受其中一部分影响——这种偏差很难被察觉。

### 2.3 多份素材各有用途时，写明角色

多份参考素材各有不同用途时，**在提示词里写明每份素材的角色**（如"图 1 为主体参考，图 2 为风格参考，图 3 为构图参考"），否则模型不知道该从哪张提取什么。
