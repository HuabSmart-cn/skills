# 电商详情图 / 亚马逊 A+ 模块

从用户的产品实拍出发，产出一叠统一画幅、可以叠成整页的详情页模块图。

## 不可退让的前提：参考图保真

本场景存在的理由是**参考图保真**：每个模块都从用户的产品实拍派生；产品本身不许改。这是电商合规要求，不是风格选择。

**每个模块的生成请求都必须带上产品实拍作参考图。绝不许降级成纯文生图** — 那会画出一个跟用户产品不一样的商品，等于改产品，是合规红线。参考图带不进去时，**在生成任何模块之前终止整个场景**：说明目前无法保证产品与实拍一致，在这个前提下交不出详情图。

## 范围边界

**做**：详情页 / A+ 模块图（below-the-fold 的模块叙事）。

**不做**（这些是别的场景或别的交付物）：
- **轮播主图**（缩略图可读的钩子图）— 那是另一套逻辑：冲击力强、文字少
- **listing 文案**（标题 / 五点 / 描述 / 后台关键词）— 那是文字交付物，不是图
- **关键词研究、表格文件**

| 本场景（详情模块） | 不是 — 轮播主图 | 不是 — 文案 | 不是 — 虚构产品 |
|---|---|---|---|
| below-the-fold 的模块叙事 | 缩略图可读的钩子 | 标题 / 五点 / 后台文案 | 重新设计过的产品 |
| 编辑向，允许多一点文字 | 冲击力强、文字少 | 文字交付物 | 用户的真实产品 |
| 完整的顾虑推进弧 | 单个抓眼球 | 表格 / 字段 | 忠实于实拍 |

**产品实拍是必填输入。** 用户没给就停下问；不许从文字虚构一个产品。

## 1. 统一画幅 — 整叠读起来像"一页"的第一件事

过关的详情页不是几张散的专题横幅；它是**等宽模块叠成的一页连续页面**。这点做错了，单张再好看也像一堆互不相关的海报。渲染前先锁死：

**整套锁定一个画幅。** 每个模块按**完全相同的尺寸**生成，不只是同宽。常见的标准详情模块是横版（比例约 1.6:1）；要宽幅时，用同高更宽的画幅。**不许任何模块漂到别的尺寸或比例** — 不要竖版、不要方形、不要"更高的一条"。**把确切尺寸写进每一条模块提示词**（模型对提示词里写明的尺寸比单靠比例参数更可靠）。

尺寸不一致是整套图散掉的第一原因。交付前逐张核对。

**用标准模块版式来搭，不要自由发挥。** 每个模块都应该能认成下面其中一种：

- **品牌头图** — 通栏生活方式 / 头图 + 标志 + 一行标题（叠字或侧栏）
- **图文分栏** — 一边图，一边标题 + 短段；沿页左右交替，做出节奏
- **图片宫格（3–4 格）** — 一排等大格子，每格一个短标签（使用场景 / 搭配宫格）
- **图标 + 文字行** — 一排 4–6 个图标配短卖点标签，没有产品图
- **对比** — 公平、具体的前后或对竞品（只有公平对比存在时才用）
- **规格 / 尺码** — 合身信息放在生活方式图旁边，用画得出来的形态呈现（见下）

**先锁定版式，再填内容。** 规划阶段就定每个模块用哪种版式；不要现场给每个模块发明新版式，也不要逼所有模块用同一种。

## 2. 把图形密集的元素设计成"画得出来"的形态

图片生成对密集多行表格、精确图标网格、锚在精确位置的引出线**极不可靠** — 出来就是糊的，这也是产出"不像真详情页"的首要原因。没有代码合成图层，就不要向模型要这些精密形态；绕着设计：

- **尺码 / 规格** → 用**尺码带**：干净条上几个大号、间距充裕的带标签数字（如 "新生儿 · 5–8 lb" / "0–3M · 8–12 lb"）；**不要**用密的多行多列表格。真实尺码分段跨很多行时，合成几个有代表性的区间。
- **图标 / 卖点** → **一排 4–6 个干净图标**，短标签、间距充裕；**不要**用紧的 2×3 精密网格；每个图标简单、风格一致。
- **标注 / 细节标记** → **编号角标放在细节旁边**（1、2、3 各配一个短标签）；**不要**用像素锚定的引出线；角标放在留白处，禁止压在脸上。
- **文字** → 标题 / 副标题 / 说明要短，高对比留白够。避免会被糊掉的细密小字。

判断规则：**一种形态只有像素级精度才好看，就换成模型能画清楚的宽松形态。**

## 3. 模块槽位系统（叙事弧）

规划一条递进故事线；**每个模块回答一个不同的买家顾虑**（同一个卖点不许重复）。只挑产品真正需要的子集；不是全都要：

| 槽位 | 内容 |
|---|---|
| 品牌 / 价值头图 | 可信度和品类定位 |
| 问题 / 解决方案 | 买家的痛，然后产品的回答 |
| 核心卖点 + 证据 | 主张 + 视觉证据（比轮播更深） |
| 结构 / 细节说明 | 机制怎么工作、为什么可靠 |
| 场景延展 | 产品在不同场景、给不同的人 |
| 规格 / 尺码 | 尺寸、区间、兼容、承重 |
| 安装 / 保养 / FAQ | 只有这些真是买家顾虑时才做 |

**节奏规则**：两个模块讲同一件事，就合并（如承重 + 钢材厚度 = 一个耐用模块），或丢掉一个。**不要用弱模块凑数。**

### 买家决策逻辑（渲染前先规划）

先画出买家顾虑的推进，再每个顾虑配一个模块：

1. 适不适合我？（合身、尺码、容量）
2. 稳不稳 / 安不安全 / 可不可靠？（结构、材质、证据）
3. 我实际能拿它做什么？（多用、模式）
4. 值不值这块空间 / 这个价？（耐用、价值、家里合不合）
5. 怎么用？（安装、调节、保养）

每个模块写清楚：**顾虑**（买家在犹豫什么）→ **主张**（看完后应该相信什么）→ **证据**（图里什么让它可信）。相关主张合并；已经回答过的或站不住的顾虑跳过。

## 4. 品类适配 — 服装 / 时尚

上面的槽位是按硬货语言写的（尺寸、容量、家里合不合）。产品是**服装、鞋履或可穿戴配饰**时，下面的覆盖规则**优先于**通用指引：

### 必须出全身模特

主体是服装的每个模块，都必须把衣服呈现在一个**完整、从头到脚、自然摆姿的模特**上 — **不要从脖子往下裁、不要悬浮 / 平铺的衣服、不要无头人台**。这条规则就是为了拦住那种失败。

**唯一例外**：专门的细节模块本身就是一排 3 个微距特写（没有全身模特），那是它的正确形态。这条规则适用于其余每个服装模块（头图、场景、尺码）。

### 服装一致性

每个呈现服装的提示词都必须写：*完整复现参考图里的这件衣服——不要改颜色、不要改花纹、不要改剪裁、不要改款或重画，并在所有模块里完全一致*。并且**每次都附上同一张参考图**。

### 服装模块映射

- **品牌头图** — 标志 + 一个材质 / 核心卖点标题 + 穿着这件衣服的全身模特作头图 + 只有真实 Logo
- **卖点图标** — 一个情绪标题 + 一排 4–6 个干净图标配短标签（面料、剪裁、场合、保养）
- **细节特写** — 渲染成**3 个并排的微距特写格**，每格是一个**不同**工艺细节的紧裁（车缝、织纹、领口、腰头、五金、里布），每格一个短卖点标签。**不要试图在一张头图里嵌 3 个微距小窗** — 模型画不稳这种合成结构，会把小窗塌成文字。要生成的是干净的一排 3 个独立特写。3 个特写各对应一条写成文的卖点。**不许少于 3 个不同的细节特写。**
- **场景 / 搭配宫格** — 一个标题 + 3–4 张不同场景 / 场合的全身模特图，各带一个情境标签
- **尺码** — 一张全身生活方式模特图 + 一条画得出来的尺码带。用品牌的**真实**尺码分段数字；修身款 / 童装还要加身高体重区间，减少退货

### 服装最少模块数

**每一套服装 / 鞋履都必须有尺码模块** — 它是抑制退货的最大手段，**不许当成"弱模块"删掉**。因此一套服装详情图**至少 4 个模块**：头图 + 至少一个证据模块（细节特写和/或卖点图标）+ 搭配场合 + 尺码。

**不许交付一套缺了尺码模块的 3 模块服装套。** 没有真实尺码分段数字时，**问用户**；不要跳过这个模块，也不要编造尺码。

### 服装合规红线

- 用**真实**面料名（如 "竹纤维粘胶" 而不是 "竹纤维面料"）
- 不要做未经核实的性能 / 环保 / 安全宣称
- **只用真实尺码分段；不许编造尺码**

## 5. 版式与文字

### 文字层级：每个带字的模块都有三层

**不要交付只有一行短标题的模块。** 渲染前先写好每一层的实际文案：

1. **标题** — 2–5 个词，最大，功能利益（如 "柔软亲肤面料"）
2. **副标题** — 一句完整的利益句，中等字重（如 "柔软亲肤的面料，让全家一整季都舒适。"）
3. **说明 / 支撑句** — 一句短的安心或规格句，最小

再加上**标注**，凡是标了部件的地方都要有。只有纯生活方式 / 头图可以降到两层；规格 / 尺码模块用尺码带当正文。

如果发现只渲染了一行标题，补上副标题和说明。每一层都要短，间距充裕。

### 版式决策（逐模块）

每个模块都做一次有意识的版式决策；不要整套跑一个模板：

- **标题** — 模块引入新概念或叙事转折时用；画面自己能说明时不用（生活方式场景、微距细节）。标题用功能利益语言，不要海报口号，并且**每个标题都必须有视觉证据**。
- **细节模块** — 一排 3 个微距特写（见上）。其他模块用 2–4 个编号角标放在细节旁边，跨模块变换处理（角标、侧色条、行内标签）。
- **尺码 / 尺寸** — 只放在专门的合身 / 规格模块，用尺码带；**不要塞进生活方式场景**。
- **对比** — 只有公平、具体、不侵权时才用；避免泛泛的"传统方式 vs 新方式"。
- **三层纵深** — 前景钩子（细节 / 数字 / 角标）→ 中景产品证据 → 背景语境。
- **文字密度** — 可以比轮播多一点字，但可见文字控制在大约 25–30%；有意识留白。
- **编辑向 vs 技术向** — 品牌 / 问题 / 场景用编辑向（暖、叙事）；规格 / 结构用技术向（干净、图解、浅灰）；带证据的核心主张用混合。

### 颜色和标签多样性

- **强调色**取自产品、品牌识别、品类惯例或用户参考 — 没有固定默认。强调色用在**一个**关键词 / 数字 / 结构元素上，不要铺到每一段文字。
- 文字和背景**高对比**；中性背景（白 / 浅灰 / 暖调）让产品和强调色跳出来；**变换场景**，不要整套单调。
- **按模块角色变换标签系统**（大号强调主张 / 细尺码线 / 彩色兼容条 / 圆形细节泡 / 图标+文字叠 / 无字生活方式）。如果每个模块都是白底小黑字标签，整套看起来像自动生成的 — 拒掉。

## 6. 锁定设计系统（锁一次，整套原文复用）

渲染前锁定一套小的设计系统，记进计划，并**在每条模块提示词里重复同一组 token**：

- **画布尺寸（先锁这个）** — 整套一个固定尺寸，写进每条提示词。这是整叠读起来像一页的关键 token；**不许逐模块漂移**。
- **每个模块的版式** — 规划阶段就定用哪种标准版式
- **视觉风格关键词** — 3–5 个氛围词 + 一句光线 / 氛围
- **色彩体系** — 主色 / 辅色 / 强调色 / 背景。每个模块强调色只用在一处
- **字体系统** — 标题用一款重无衬线，正文用一款常规无衬线；定好每一层文字用什么颜色，跨模块一致
- **视觉语言** — 反复出现的装饰母题和图标风格，复用好让模块读起来是一套
- **质量** — 要求分辨率够高，标题 / 标签仍然可读

### 绝不把规格画进画面

上面这些值是**给你的指令，不是图上内容**。渲染时，色值代码、字体名、章节标题词、字段标签词（"标题"、"副标题"、"尺码表"）、结构说明或提示词文字**不许**出现在图上。**只有真正面向顾客的文案**（实际的标题 / 副标题 / 说明 / 标签 / 尺码数字）可以出现。

图上写 `柔软亲肤面料`，不要写 `标题：柔软亲肤面料`。

## 7. 参考图保真交接（本场景的核心）

> 通用锚点链和系列一致性方法在 `series-consistency.md`。本节只写本场景的产品保真要求。

产品一致性完全靠**把用户的产品图作为参考图交给生成**：

1. 把用户的**产品实拍**当作唯一事实来源。
2. **每个模块**都从产品图生成 — 把那张产品图原样附上当参考；**不许用纯文字重述，不许用"之前那个产品"**。
3. 每条模块提示词都写明：保持产品的**精确外观** — 形状、比例、材质、颜色、标识、产品上的真实文字 — **不变**；只改场景、版式、标注和语境。不要重新设计或改款产品。
4. 用户给了多个产品角度 / 变体时，用**最有代表性的**作主基线，其余作辅助参考。参考图数量有上限时，按 core `input-contract.md` 处理（说明上限，保留前 N 张，或询问）；**不要静默丢弃**。
5. 纯背景 / 场景板（**没有**产品）可以从文字生成，但产品必须始终来自实拍。
6. **服装**：参考图通常是平铺 / 挂拍 — 指示生成**让一个完整的全身模特穿上这件衣服**，同时保持衣服的颜色、花纹、剪裁和比例完全一致。

还没拿到产品图时，**停下来先要到**。

## 8. 分镜规划（渲染任何模块之前，先列出互不相同的照片）

**这一步是为了拦住本场景的第一大失败：每个模块都在复用几乎同一张产品图。**

不要让每个模块懒惰地从实拍再派生同一姿态 / 场景。渲染前，先规划整套需要的**互不相同的照片**：

**1. 列出每张互不相同的照片**，每张都是不同的场景、姿态、取景或裁切。一套服装通常至少意味着：
- 一张**头图生活方式**（全身，环境 A）
- **3–4 张场景**图，每张都是真正**不同**的环境 / 活动（如床上入睡 / 早上地板上玩 / 户外 / 沙发上放松）— 背景、姿态和光线都不同，**不是同一张照片换了色**
- **至少 3 张细节特写**，每张是一个**不同**细节的紧微距裁，**不是**又一张全身
- 一张**尺码 / 合身**全身图（可以和头图不同）

**2. 对照模块去重**：把每张照片映射到使用它的模块。两个模块用同一张照片是**红旗** — 要么做出区分（新场景 / 姿态 / 裁切），要么确认这次复用是有意的。**头图和尺码模块不许共用同一张照片。**

**3. 先生成这些互不相同的底图**，再用它们搭模块。每张生成的照片都必须和其他张**明显不同** — 变换环境、机位、姿态、裁切、光线，同时保持产品 / 服装完全一致。

**4. 模块需要多格时**（如 3–4 格场景宫格），每格按不同场景单独生成；**不许用一张照片重复填宫格**。

### 按语义角色组织，不要按顺序

给每张底图起一个**语义角色名**（如 主视觉、场景-入睡、细节-织纹、尺码图）；一个角色，一次生成请求。规则见 core `output-contract.md` 和 `series-consistency.md`。

本场景最容易犯的错：一次请求返回多张图，再**按返回顺序分给不同模块** — 顺序不保证符合意图，对不上会把整套标错（尺码图配了细节文案，等等）。

开始渲染前，记下分镜表（角色名 → 场景/姿态/裁切 → 哪个模块用它）。

## 9. 流程

### 阶段 1 — 收需求和产品素材
1. **产品实拍**（必填；缺了就停下问）
2. **品牌名 / 品名** — 头图或标题需要时**问一次**；用户不给，就做**无品牌 / 无品名版本**（去掉标志元素，标题改成中性品类通称），**不许编造品牌名、品名或标志**（和改产品同一级的合规红线）
3. **卖点 / 规格**（尺寸、材质、容量、功能、差异点）— 问一次；还是不给，就从产品图可见信息和品类惯例推导合理、不编造的卖点，避开任何无法核实的性能 / 环保 / 安全宣称
4. **目标市场和语言** — 图上文字默认跟目标市场；用户要另一种语言 / 双语 / 无字就跟随
5. **品牌调性 / 强调色 / 参考图**（只作方法参考，不许抄竞品）
6. **品类**（从产品图判断是不是穿戴类：服装 → 全身模特规则 + 必做尺码模块）和目标买家

### 阶段 2 — 买家顾虑图和模块计划
1. 列出这个产品的买家顾虑推进
2. 挑产品真正需要的槽位子集，每个配一个不同的顾虑
3. 每个模块写顾虑 → 主张 → 证据，相关主张合并，不是异议的跳过
4. **现在就写好每个模块的实际文案** — 标题 + 副标题 + 说明 + 标注（真正面向顾客的文案，用目标语言）。**不要把文案拖到渲染时再写**；没写好三层文案的模块不许进入渲染

### 阶段 3 — 锁定视觉风格
锁定画布尺寸（先锁）、每个模块的版式、强调色、整套设计系统。见第 6 节。

### 阶段 4 — 分镜规划
列出互不相同的照片，对照模块去重，起语义角色名。见第 8 节。

### 阶段 5 — 先生成底图，再搭模块
1. **按语义角色一张张生成底图**（一个角色一次请求），从产品图派生，产品保持一致
2. 用分配给它的底图搭每个模块，套上该模块的版式决策和标签处理
3. 保持产品外观一致；改场景 / 姿态 / 裁切 / 版式，让模块彼此明显不同
4. 记下每个模块用了哪张照片，以及它的顾虑 / 主张 / 证据

### 阶段 6 — 交付前门禁
跑下面的清单；不过的模块必须**从产品图重新生成**。

## 10. 交付前门禁（不过就重做）

- **统一画幅（硬门禁）** — **每个**模块都是锁定的尺寸；逐张核对；**任何偏差都拒**，哪怕只偏一点点。尺寸错了 → 把确切尺寸写进提示词重新生成。
- **产品保真** — 形状、比例、材质、颜色、标识、产品上的真实文字与用户照片**完全一致**；没有重新设计、改款或编造。
- **没有编造的品牌 / 品名（硬门禁）** — 图上出现的每个品牌名、品名和标志都来自用户（原文）。用户没给 → 就是无品牌 / 无品名版本，**没有**编造的名字或标志。用户没提供的任何东西 → 拒掉重做。
- **服装全身模特** — 除了专门的细节模块，每个服装模块都是**完整的全身模特、自然摆姿**（不要从脖子往下裁，不要平铺 / 悬浮衣服当唯一呈现，不要无头人台）。不过 → 用全身模特重做。
- **服装尺码模块在** — 服装套包含一个带**真实**尺码分段数字的尺码模块，整套至少 4 个模块。缺了尺码模块的 3 模块服装套不过 → 补上。
- **顾虑各不相同** — 每个模块回答一个不同的买家问题；没有两个重复同一个卖点。
- **照片多样性（硬门禁）** — 没有两个模块用同一张或几乎同一张照片。场景宫格的每一格都是真正不同的环境；细节模块用紧微距裁而不是又一张全身；**头图和尺码模块不是同一张照片**。两个模块看起来像同一张照片换了文字 → 按分镜表用新场景重做其中一张。
- **细节特写 ≥3、横排（硬门禁）** — 细节模块是**3 张并排的微距特写图**，每张是一个不同真实细节的裁切，带一个卖点标签。失败形态：少于 3；模块是全身 / 生活方式图，细节写成纯文字条目；特写重复或泛泛。→ 重做成 3 个不同的微距特写格，**每个特写单独生成**。
- **版式决策对得上** — 标题只在配得上时出现（并且有视觉证据）；尺码带只在合身 / 规格模块；对比公平且具体。
- **文字层级完整** — 每个带字的模块都有完整的三层（标题 + 副标题 + 说明）+ 标注，不是孤零零一行标题。→ 补上并重做。
- **画得出来的图形** — 表格是尺码带（不是密表），图标是间距充裕的一排干净图标（不是紧网格），细节标记是编号角标（不是锚定引出线）。糊掉的密表 / 网格或对不齐的引出线 → 换成画得出来的形态重做。
- **图上没有规格 / 元数据** — 画面里**零个**色值、字体名、章节标题、字段标签词或提示词文字；只有真正面向顾客的文案。→ 重做。
- **标签多样性** — 标签 / 处理系统按模块角色变换；整套看起来不像自动生成（不是全是白底小黑字标签）。
- **文字密度和可读** — 可见文字大约 25–30%；标题和标签清晰；语言整套一致。
- **版式能认出来** — 每个模块都是能认的标准版式，不是即兴横幅。
- **强调色纪律** — 强调色用在关键词 / 数字 / 元素上，不要铺到每一段文字。
